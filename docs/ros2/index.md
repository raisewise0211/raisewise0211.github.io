# ROS2

ROS2는 로봇 소프트웨어를 만드는 미들웨어이자 생태계다.
이 섹션은 ROS2 기반 프레임워크와 패키지의 내부 동작을 **코드 수준에서** 분석하고,
직접 확장·커스터마이징하는 방향까지 정리한다.
